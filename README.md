# Banking Data Integration – SSIS ETL

## Overview

This project implements a basic-to-intermediate ETL (Extract, Transform, Load) pipeline using SQL Server Integration Services (SSIS) within Visual Studio.

The objective is to extract banking data from CSV files, perform data transformations and quality validations, and load the processed information into a SQL Server database.

## Objectives

- Develop a practical ETL workflow using SSIS.
- Extract data from flat files (CSV).
- Perform data type conversions and data transformations.
- Implement basic data quality validation rules.
- Separate valid and invalid records.
- Load processed data into SQL Server staging tables.
- Document the ETL architecture and execution process.

## Technologies

- Microsoft Visual Studio
- SQL Server Integration Services (SSIS)
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Git and GitHub

## Dataset

The project will use the Bank Marketing dataset from the UCI Machine Learning Repository.

Source: https://archive.ics.uci.edu/dataset/222/bank+marketing

## ETL Workflow

1. Extract: Read banking data from CSV files.
2. Transform: Convert data types and create derived columns.
3. Validate: Apply data quality rules and separate invalid records.
4. Load: Store processed records in SQL Server.
